RTSP Camera 지원

아이폰을 RTSP 카메라 서버로 만드는 송출 앱 · iOS 18 이상

핵심: 이 앱은 기기 자체가 송출 서버가 됩니다. 영상을 보려면 같은 네트워크의 다른 기기가 앱에 표시된 주소로 접속해야 합니다 — VLC 같은 RTSP 플레이어, 또는 앱 설치 없이 웹 브라우저로 볼 수 있습니다.

빠른 시작

  1. 아이폰을 Wi-Fi에 연결합니다.
  2. 앱에서 “송출 시작”을 누르고 카메라·마이크·로컬 네트워크 권한을 허용합니다.
  3. 첫 송출 때 연결 도우미가 열려 두 주소를 보여줍니다(QR·복사·공유). 이후에는 주소 옆 ?나 설정 → 연결 방법에서 열 수 있습니다.
    예: http://192.168.0.9:8080(웹 브라우저), rtsp://192.168.0.9:8554/live(RTSP 플레이어)
  4. 웹 브라우저로 보기: 같은 Wi-Fi 기기의 Safari·Chrome에서 http:// 주소를 엽니다. 거의 실시간인 빠른 보기(소리 없음)가 나오고, 소리까지 들으려면 페이지의 “소리와 함께 보기”를 누릅니다(약 6~10초 지연).
  5. VLC로 보기: PC/Mac에서 VLC를 열어 파일 → 네트워크 열기에 rtsp:// 주소를 붙여넣습니다. (터미널: ffplay -rtsp_transport tcp rtsp://<폰IP>:8554/live) 수 초 내 실시간 영상과 음성이 재생됩니다.

자주 묻는 질문

VLC나 브라우저에서 영상이 안 보입니다.

  • 송출 중에 주소 옆 ?를 눌러 연결 도우미의 연결 상태를 확인하세요. 네트워크·접속·인증·재생 중 어느 단계에서 막혔는지와 해결 방법을 알려줍니다.
  • 폰과 클라이언트가 같은 Wi-Fi(같은 서브넷)에 있는지 확인하세요.
  • 최초 실행 시 로컬 네트워크 권한을 허용했는지 확인하세요. (iOS 설정 → RTSP Camera)
  • 회사·공용 Wi-Fi는 기기 간 통신(P2P)을 차단하는 경우가 있습니다. 가정용 공유기나 개인 핫스팟에서 시도하세요.
  • 주소의 IP가 폰의 현재 IP와 일치하는지 확인하세요(네트워크가 바뀌면 IP도 바뀝니다).

다른 앱을 보다 오면 송출이 멈춥니다.

iOS는 백그라운드 카메라 캡처를 허용하지 않습니다. 송출은 앱이 화면에 떠 있는 동안에만 동작합니다(정상 동작).

아무나 내 스트림에 접속할 수 있나요?

인증은 기본 꺼짐입니다. 신뢰할 수 없는 네트워크에서는 설정 → 접속 보안에서 인증을 켜세요. 같은 계정이 RTSP와 웹 브라우저 시청에 모두 적용되며, 자격증명은 기기 Keychain에 저장됩니다. 브라우저 시청이 필요 없으면 설정 → 브라우저 시청을 꺼 둘 수 있습니다.

외부(셀룰러)에서 보고 싶습니다.

선택 기능인 셀룰러 송출은 사용자가 직접 준비·운영하는 RTMP 릴레이 서버(MediaMTX 등)로 푸시하는 BYO 방식입니다. 릴레이 주소와 스트림 키를 입력해 사용합니다.

오디오가 안 나옵니다.

마이크 권한을 허용했는지, 클라이언트(VLC)의 음소거·볼륨을 확인하세요.

브라우저에서 소리가 안 나옵니다.

  • 기본 화면(빠른 보기)은 소리가 없습니다. 페이지 아래 “소리와 함께 보기”를 누르세요.
  • 소리 포함 보기는 자동재생 제한 때문에 음소거로 시작합니다. 플레이어의 스피커 아이콘을 눌러 소리를 켜세요.
  • Safari가 아닌 브라우저(Chrome 등)는 재생 스크립트를 인터넷에서 받아오므로 시청 기기가 인터넷에 연결되어 있어야 합니다. 인터넷이 없으면 Safari나 VLC를 이용하세요.

소리 포함 보기가 실제보다 늦게 보입니다.

소리 포함 보기(HLS)는 구조상 약 6~10초 늦게 보입니다. 지연 없이 영상과 소리를 보려면 VLC 등 RTSP 플레이어를 이용하세요.

화질을 바꾸고 싶습니다.

설정 → 송출 화질에서 저화질(540p)·표준(720p)·고화질(1080p)을 고를 수 있습니다. 다음 송출부터 반영되며, 카메라가 지원하지 않는 화질은 자동으로 한 단계 낮춰 적용됩니다. 고화질은 발열과 네트워크 사용량이 늘어납니다.

요구 사항

  • iOS 18 이상 (실기기 — 카메라 사용)
  • 시청 기기: 웹 브라우저(Safari·Chrome 등) 또는 RTSP 클라이언트(VLC, ffplay, NVR 등)
  • 로컬 시청: 폰과 시청 기기가 같은 네트워크

문의

문제가 해결되지 않으면 아래로 연락 주세요. 사용 중인 iOS 버전, 기기 모델, 네트워크 환경(가정/공용)을 함께 적어 주시면 빠르게 도와드립니다.
